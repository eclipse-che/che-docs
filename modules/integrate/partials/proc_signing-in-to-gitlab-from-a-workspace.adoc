= Signing in to GitLab from a workspace

Sign in to GitLab with OAuth from the GitLab Workflow extension that runs in a workspace. A successful sign-in also verifies that the GitLab application and the GitLab Workflow OAuth configuration are set up correctly.

.Prerequisites

* Registering a GitLab application for the IDE redirect and mounting the GitLab Workflow OAuth configuration are completed.

* A workspace is running with an editor based on Visual Studio Code, such as Che Code, and with the GitLab Workflow extension installed.

* You are signed in to {prod-short} in the browser in which the IDE runs. The OAuth redirect requires an active {prod-short} session.

.Procedure

. In the sidebar of the IDE, open the *GitLab* view.

. Start the sign-in, for example by clicking *Authenticate to GitLab*.

. In the *Select GitLab instance* list, select the instance that the GitLab application is registered on.

. In the *Select authentication method* list, select *OAuth*.

. In the browser tab that opens, review the permissions and click *Authorize*.
+
GitLab redirects back to {prod-short}, which forwards the authorization code to the workspace. The IDE shows a notification that a GitLab account is added.

.Verification

* Verify that the *GitLab* view lists your issues and merge requests.
