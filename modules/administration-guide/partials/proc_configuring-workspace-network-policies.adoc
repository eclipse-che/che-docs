= Configure network policies for workspaces

[role="_abstract"]
Configure network policies for workspaces to restrict the traffic to and from workspace Pods.
The {devworkspace} Operator provisions one NetworkPolicy for each workspace, controlled by the `spec.devEnvironments.networking.networkPolicy` CheCluster field.
Workspace network policies are disabled by default.


.Prerequisites
* An active `{orch-cli}` session with administrative permissions to the destination {orch-name} cluster. See {orch-cli-link}.

.Procedure
. Enable network policies for workspaces:
+
[source,shell,subs="+quotes,+attributes"]
----
{orch-cli} patch checluster/{prod-checluster} \
  --namespace {prod-namespace} \
  --type merge \
  --patch '{"spec":{"devEnvironments":{"networking":{"networkPolicy":{"enabled":true}}}}}'
----

. Optional: Define custom `ingress` and `egress` rules in the `spec.devEnvironments.networking.networkPolicy` field to restrict the traffic that is allowed for the workspace Pods.
A non-empty `ingress` list replaces the default rules, so include rules for the traffic that must still be allowed, for example traffic from the {prod-short} components:
+
[source,yaml,subs="+quotes,+attributes"]
----
spec:
  devEnvironments:
    networking:
      networkPolicy:
        enabled: true
        ingress:
          - from:
              - namespaceSelector:
                  matchLabels:
                    kubernetes.io/metadata.name: __<peer_namespace>__
----
+
In this example, the workspace accepts ingress traffic from Pods in the `__<peer_namespace>__` {orch-namespace}.
+
For how the `ingress` and `egress` fields behave when they are not specified, empty, or non-empty, see xref:configuring-network-policies.adoc#workspace-network-policy-rules[].

.Verification
* Start a workspace and verify that the NetworkPolicy resource is created for it in the user {orch-namespace}:
+
[source,shell,subs="+quotes,+attributes"]
----
{orch-cli} get networkpolicies -n __<user_namespace>__
----

[NOTE]
====
The new configuration is applied to a workspace the next time that workspace is reconciled, for example when it is started or stopped.
====
