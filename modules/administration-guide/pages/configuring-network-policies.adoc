= Configure network policies

[role="_abstract"]
To restrict Pod-to-Pod traffic, enable network policies for the {prod-short} components, for each workspace, or for both.
The {prod-short} Operator manages the NetworkPolicy resources for the components, and the {devworkspace} Operator provisions a NetworkPolicy for each workspace.
Both features are disabled by default.
