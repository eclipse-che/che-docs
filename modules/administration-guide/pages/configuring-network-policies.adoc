= Configure network policies

Network policies control Pod-to-Pod communication in a {orch-name} cluster.
The {prod-short} Operator can manage the NetworkPolicy resources for the {prod-short} components automatically,
and the {devworkspace} Operator provisions a NetworkPolicy for each workspace.
